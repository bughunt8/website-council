# Wireframe and states

## Desktop

Header with Council identity, room navigation, guide, source code, and theme.

Left-aligned introduction. The decision-room workspace uses a broad left stage with seven advisors above a table and an active argument card. The right column contains example selection, context, three options, and one primary replay action.

Playback controls sit below the stage. The growing transcript follows the workspace. The closing editorial section explains dissent and smaller tests. Footer links to Ronald Ng, code, private setup, attribution, and licenses.

## Mobile

Single column. The advisor stage stays above the decision panel. Nameplates wrap rather than requiring horizontal scroll. Transport chapters remain accessible. Transcript becomes one column, and dialog forms become one column.

## State transitions

- Initial: curated recorded example loaded; no claim of live execution.
- Replay: active speaker and argument; recorded replay label; pause/speed/seek.
- Paused: visible resume action.
- Complete: scored options and verdict/replay actions.
- Error: specific loading failure and retry action.
- Advisor: native modal with available recorded round tabs.
- Verdict: native modal with details, PDF, and report.
- Brief: native modal, local command generation, explicit no-transmission copy.
