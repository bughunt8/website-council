# Council agent rules

Read README and its full document spine. The service must execute profile discussions and conclude using authorized company memory. Do not downgrade it to a static replay site.

- Work through feature/staging PRs; do not push to main.
- Private Backend owns host, data, identity, tunnel and activation. This public repository owns executable code and public advisor provenance.
- No private company corpus/config/keys in repository, build context, image, example catalog, or preview artifact.
- Runtime injects identity/model/budget config, separate profile data, key files and private session state.
- Use the same source-bounded frozen evidence throughout a run. Missing/unauthorized memory blocks model execution.
- Auth, quotas, concurrency and disclosure approval precede costs. Never silently replay an example or automatically retry a failed paid council.
- Do not trust email headers, expose all sessions, allow caller model/source override, or share global usage between users.
- Keep usage/provider keys server-side. Do not run paid smoke tests without owner approval.
- Brain reads are scoped; model conclusions do not become company facts automatically.
- Image build and mock tests do not prove real vectors/models/live hosting. Track unfinished acceptance as issues and qualified receipts.
