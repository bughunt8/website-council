Profile-based discussion.

The company service sends your brief and an authorized memory pack to the model-backed profiles, circulates their arguments, and produces a chair's conclusion. Sign-in and usage approval are required. Examples are separate recorded demonstrations. The original local workflow is also available.

  1. Clone the repository.git clone https://github.com/bughunt8/website-council.git
    cd website-council
  2. Start the local room.npm startOpen http://localhost:4730.
  3. Open Claude Code in the same folder.claude
  4. Type /roast-room followed by your decision. Answer the Chair's questions, then watch the room.

Claude Code and Node.js 20 or newer are required. Your Claude subscription's usage limits apply. Full councils use more of your allowance than --quick. The optional local API runner bills your own Anthropic account independently of the company service.
